A live card

Add it to a website

Replace the item ID with a stable ID from the catalog. Include the script once; it renders each matching container. The card keeps creator credit, review information, source links and the data-license link.

<div data-u1-item="stock-burn-in-complete"></div>
<script src="https://KellenWat.github.io/u1-starthere/embed.js" defer></script>

The script fetches public data without credentials, uses its own isolated styles, and saves no browser data. A host page must allow external scripts, HTTPS data requests and embedded custom elements. Forums that strip scripts should use a normal item-page link instead.

For a container created later, call window.U1StartHere.render(element, itemId) after the script loads. Unknown IDs or unavailable data show a link back to the catalog.
