SpoolKid

Manage filament on iOS, scan labels and work with NFC tags. A small local library can be used before connecting a Spoolman server.

Will this work for my setup?

Printer / firmware
The phone app can work independently. U1 custom-tag reading needs compatible extended firmware and a supported physical tag.
Accounts and services
TestFlight access is used for the current beta. Spoolman is optional for the local library.
Extra hardware
An NFC-capable iPhone for tag features; camera access for optional label scanning.
Project license
The repository is an older public snapshot; current development is private. See author terms for the distributed beta.
