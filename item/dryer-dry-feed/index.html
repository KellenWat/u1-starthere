Filament system / Dry-feed and tune

Route dryer feed and set profiles

Route PTFE from the dryer to the feeders without tight bends. Select filament profiles manually when remote spools no longer pass the built-in RFID readers.

Cost
Free
Estimated time
30 min
Difficulty
Some setup 2 of 5
Reversible
Usually, yes

What to budget

Setup adds no new purchase if dryer and suitable tubing are already available; otherwise budget for them separately.

Before you start

  • Creality Space Pi X4 dryer

Read before changing anything

  • RFID auto-detection is lost when dryer spools are away from the built-in readers. Set each feeder's filament profile manually.
  • OpenSpool tags are an optional remedy with extended firmware and deliberate placement near the reader.

Optional next steps

These are separate choices, not required purchases.
