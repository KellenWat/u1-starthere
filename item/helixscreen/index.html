An overview to help you choose. Follow the linked creator guide for the actual installation.

  1. Check the current U1 integration guide and its camera limitation.
  2. Select HelixScreen through the documented firmware configuration option.
  3. Confirm the screen works and keep the documented stock-interface fallback available.
