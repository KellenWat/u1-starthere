SpoolLink companion apps

  • Companion app
  • Proof of concept

Link a tag’s unique ID to a Spoolman spool. The author labels these apps an unstable proof of concept; they do not write custom tags.

Will this work for my setup?

Printer / firmware
U1 UID-to-spool automation needs a compatible extended build with SpoolLink and Spoolman integration. The app and server are separate.
Accounts and services
A reachable Spoolman server is required. iOS builds need the documented NFC entitlement/developer setup.
Extra hardware
An NFC-capable phone; the web variant has additional browser and server constraints.
Project license
GPL-3.0.
Plan this option

Setup outline

An overview to help you choose. Follow the linked creator guide for the actual installation.

  1. Connect the app to the same Spoolman server used by the U1.
  2. Scan one tag and link it to a spool.
  3. Check the assignment in Spoolman and on the printer before linking a batch.
