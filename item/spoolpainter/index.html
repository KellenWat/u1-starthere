SpoolPainter

  • Companion app
  • Documented

Manage spool inventory and read or write OpenSpool NFC data from Android. The app can pair tag IDs with a self-hosted Spoolman library.

Will this work for my setup?

Printer / firmware
U1 UID-to-spool automation needs a compatible extended build with SpoolLink and Spoolman integration. The app and server are separate.
Accounts and services
Uses a self-hosted Spoolman server; the project describes no separate cloud account.
Extra hardware
Android 10 or newer with NFC, plus suitable tags.
Project license
GPL-3.0.

Setup outline

An overview to help you choose. Follow the linked creator guide for the actual installation.

  1. Check Android and NFC requirements in the current release.
  2. Set the Spoolman server address and test the connection.
  3. Try one spool and tag before updating the rest of the inventory.
