Will this work for my setup?

Printer / firmware
Printer connections need reachable Moonraker. U1 SpoolLink features need compatible extended firmware and Spoolman; check the project for other workflows.
Accounts and services
Uses the server’s own access setup; review account and network configuration upstream.
Extra hardware
A Windows host; supported browser clients. Android NFC features have separate browser requirements.
Project license
Check the project’s current license and distribution terms.
